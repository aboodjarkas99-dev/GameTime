GameTime Factory Work Board

Secure V2

GameTime is the factory work-board system used to plan Batch Maker and Production work, record live progress, carry unfinished work forward, track actual filling quantities, manage Hold Line items, print the daily sheet, and review monthly production.

What We Use

VercelHosts the web application and publishes the Secure V2 website.
Supabase PostgresStores work orders, production progress, audit history and account profiles.
Supabase AuthHandles secure sign-in, sessions and management-account passwords.
Supabase RealtimeKeeps changes synchronized between factory computers and phones.
Row Level Security (RLS)Database rules decide what authenticated roles are allowed to read or change.
GitHubStores source code and version history. The repository must be Private if the source code itself should not be publicly visible.

Security Model

  • No anonymous database access to Secure V2 work data.
  • Every signed-in account has a server-side access role; changing the page or URL does not grant extra database permission.
  • Management accounts use email + password. Factory employees use Employee Code + PIN.
  • Passwords are handled by Supabase Auth; GameTime does not store readable password text in the work-order database.
  • Work-order changes are recorded in activity/audit history for accountability.
  • The publishable browser key is not treated as a secret; protection comes from authentication and server-side RLS policies.

Data & Reliability

  • The Secure V2 database is separate from the old GameTime database.
  • Live synchronization uses Supabase Realtime; the database remains the central source of truth.
  • Code backup branches are created before major releases. Database backup availability and retention depend on the Supabase plan and should be reviewed separately from audit history.
  • Automatic rollover moves unfinished scheduled work to the next business day while preserving production progress records.

Important Source-Code Privacy Note

A login protects factory data, but it does not by itself hide website source files. To prevent outsiders from finding the Secure V2 source in GitHub search, the GameTime GitHub repository must be Private.

Put GameTime on This Device

G
Open GameTime like a normal app

You can pin it to your desktop, taskbar, Home Screen, or app list so you do not need to search for the website every day.

Desktop / Laptop

  1. Open GameTime in Chrome or Microsoft Edge.
  2. Look for the Install icon near the address bar, or open the browser menu.
  3. Choose Install GameTime / Install this site as an app.
  4. Allow a Desktop or Taskbar shortcut if your browser asks.

iPhone / iPad

  1. Open GameTime in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen.
  4. Tap Add.

Android

  1. Open GameTime in Chrome.
  2. Tap the ⋮ menu.
  3. Choose Install app or Add to Home screen.
  4. Confirm Install.
