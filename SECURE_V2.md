# GameTime Secure V2

This branch is the isolated secure factory app.

- Frontend branch: `secure-v2`
- Database: separate Supabase project
- Authentication: Manager email/password; employee code + PIN
- Server-enforced roles: Manager, Batch Maker, Production, View Only
- Vercel project: `gametime-secure-v2`
- Vercel is configured to deploy only this branch.
